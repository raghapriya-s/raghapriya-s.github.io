# Ragha Priya - Portfolio

A responsive portfolio built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` with VS Code Live Server.

## Before publishing
1. Put your resume PDF at `resume/Resume.pdf`.
2. Replace `yourusername` in `index.html` with your GitHub and LinkedIn URLs.
3. Replace `yourmail@gmail.com` with your email address.
4. Update project and certification details as needed.

No build tools are required.
